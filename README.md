# PROVA-28-09-2026

PROVA 28-09-2026 - PORTAL DE FUTEBOL

SOBRE O PROJETO

Este projeto foi desenvolvido como atividade avaliativa da disciplina de HTML.

O objetivo do projeto é criar um portal sobre futebol utilizando HTML puro, colocando em prática os conhecimentos adquiridos durante as aulas.

O site apresenta conteúdos relacionados ao futebol e utiliza diferentes recursos da linguagem HTML para organizar e apresentar as informações.


OBJETIVO

O objetivo principal deste projeto é demonstrar os conhecimentos adquiridos em HTML através da criação de um site completo e organizado.

O projeto trabalha com navegação entre páginas, estrutura semântica, tabelas, formulários, imagens, áudio, vídeo e diferentes formas de organização e marcação de conteúdo.


ESTRUTURA DO PROJETO

O projeto está organizado em diferentes pastas.

A pasta audio contém os arquivos de áudio utilizados nas páginas.

A pasta html contém as páginas HTML que fazem parte do site.

A pasta img contém as imagens utilizadas no Portal de Futebol.

A pasta video contém os arquivos de vídeo utilizados nas páginas.

O arquivo README contém as informações e explicações sobre o projeto.


PÁGINAS

O projeto possui diferentes páginas relacionadas ao Portal de Futebol.

As páginas estão conectadas através de um menu de navegação, permitindo que o usuário navegue entre elas de maneira simples.

O menu está presente nas páginas do projeto para facilitar o acesso aos diferentes conteúdos.


ESTRUTURA SEMÂNTICA

As páginas foram desenvolvidas utilizando a estrutura semântica do HTML.

Foram utilizados elementos para representar o cabeçalho, menu de navegação, conteúdo principal, seções, artigos, conteúdos complementares e rodapé.

Essa organização ajuda a deixar o código mais organizado e facilita a identificação de cada parte da página.


TABELAS

O projeto utiliza tabela para apresentar informações relacionadas ao futebol de maneira organizada.

Também são utilizados recursos que permitem unir células da tabela, demonstrando os conhecimentos adquiridos durante as aulas.


FORMULÁRIO

O projeto possui formulário utilizando diferentes tipos de campos.

O formulário apresenta recursos como seleção de data, envio de arquivo, controle de valores, sugestões através de lista, campos obrigatórios e textos de orientação para o usuário.


IMAGENS

O Portal de Futebol utiliza imagens para complementar os conteúdos apresentados.

As imagens estão organizadas na pasta img.

Também são utilizadas legendas para explicar ou identificar algumas das imagens apresentadas nas páginas.


ÁUDIO E VÍDEO

O projeto utiliza arquivos de mídia armazenados localmente.

Os arquivos de áudio ficam organizados na pasta audio.

Os arquivos de vídeo ficam organizados na pasta video.

Esses arquivos podem ser reproduzidos diretamente através das páginas do site.


CONTEÚDOS EXPANSÍVEIS

Algumas páginas possuem conteúdos que podem ser abertos e fechados pelo usuário.

Esse recurso permite apresentar informações adicionais sem ocupar muito espaço inicialmente na página.


MARCAÇÕES AVANÇADAS

O projeto também utiliza diferentes recursos de marcação avançada do HTML.

Esses recursos permitem destacar informações, apresentar abreviações, indicar conteúdos removidos ou adicionados, apresentar citações e demonstrar valores de progresso ou medição.


ORGANIZAÇÃO

Os arquivos foram separados em pastas de acordo com seus tipos para manter o projeto organizado.

As páginas ficam na pasta html.

As imagens ficam na pasta img.

Os áudios ficam na pasta audio.

Os vídeos ficam na pasta video.
